## 📚 关于本站

本站用 [Hexo](https://hexo.io/) 静态生成，托管在 GitHub Pages 上，不需要服务器。文章用 Markdown 写，支持 LaTeX 公式与 SVG 图表，另外还有提示框、行内高亮、站内双链、折叠块等写法 —— 具体见 [语法速查：本站支持的全部写法](https://dayanzaihappy.github.io/PiBlog/2026/10/20/syntax-tour/)。

正文排版沿用 RS_BLUE 主题（深空蓝配科技青、浅底深字），右上角的按钮可以在亮色与暗色之间切换，选择会记在浏览器里。首页按时间倒序列出文章，也可以从「归档 / 分类 / 标签」按线索翻阅。
